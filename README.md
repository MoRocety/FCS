# FCS planning documents

This is an archive branch with no shared history with `main`. It holds the planning documents for Forman Course Scheduler, which never lived in the app repo.

| File | Written | What it is |
|---|---|---|
| `FCS-V3-PLAN.md` | Jun 2026 | A complete rebuild plan: FastAPI + Postgres + Next.js, schema, API, a 14-week schedule, an 11-phase roadmap, creative features, the agentic vision |
| `FCS-MOCKUP-PLAN.md` | Jun 2026 | UI mockup scope in 9 phases |
| `FCS-MOCKUP-PLAN-COARSE.md` | Jun 2026 | The same scope compressed into phases A–D |
| `FEATURES.md` | Nov 2026 | Every feature, sorted into built and tested, live in v1, mocked up, or planned only |
| `KNOWN_ISSUES.md` | Nov 2026 | Known v1 issues and intended behaviour |

Related branches:
- `archive/mockups`: the clickable mockups built from these plans
- `fcs/media-feed-and-exhaustive-search`: the October 2026 build, with its own `docs/` (roadmap, platform plan, architecture)

`FEATURES.md` mentions folder names like `1_Dell_Work_Jun2026/` and `2_Mac2_Personal_FCS_Oct2026/`. Those refer to the owner's private archive, not to this repository.
