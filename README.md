# FCS UI mockups (June 2026)

This is an archive branch with no shared history with `main`. It holds clickable UI mockups made from the plans in the `archive/plans` branch.

Every mockup is static HTML (Tailwind + vanilla JS) with **made-up data**. The instructors, ratings, grades and reviews are fictional placeholders, and nothing connects to a backend. To view one, open any `index.html` in a browser.

| Folder | What it is |
|---|---|
| `fcs-mockup/` | A single-page first pass |
| `fcs-mockups-phase1-9/` | One mockup per phase of `FCS-MOCKUP-PLAN.md` (`shared/components.js` is shared) |
| `fcs-mockups-v3/` | Phases A–D of `FCS-MOCKUP-PLAN-COARSE.md` as larger combined demos |
| `fcs-mockups-v4/` | The most complete set: phases A–D, a `generator/` (`build.py`, `data.json`, 26 view modules) and `screenshots/` of every view |

The v4 views are catalog, builder, saved, instructor, compare, course, Will It Fill?, health score, stress test, waitlist, seat monitor, time protector, textbooks, commute, feed, review, Semester Wrapped, agent chat, agent memory, proactive suggestions, course history, degree progress, substitution finder, career advisor, chatbot and planner.
